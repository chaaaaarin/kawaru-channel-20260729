# 🎁 できること・できなくなったこと早見表

「公式サイトの説明」と「今実際にできること」がズレやすいWorkspace Studioの現状を、4カテゴリの早見表にまとめました。

**受け取り方**: 下のコードブロック右上のコピーボタンでコピーするか、このファイルをそのままダウンロードしてください。

**使い方**: 導入検討時の「これはできる/できない」の確認資料としてそのまま使ってください。

```text
【できること・できなくなったこと早見表】

■ カテゴリ1: 公式ヘルプが明記する上限
□ 作成できるフロー数
→ 現状: 最大25個(オン/オフ問わず全て)

□ 1フローあたりのステップ数
→ 現状: 最大20ステップ

□ Gmailイベントで起動できるフロー数
→ 現状: 最大25個(アクティブなもののみ)

■ カテゴリ2: 正式リリース後に消えた機能
□ Webhookステップ
→ 現状: 2025年12月の正式リリースで削除。復活は未確認

□ Chatスペースへの投稿ステップ
→ 現状: 同上、削除された状態

□ GAS(Google Apps Script)との連携
→ 現状: 一時的に利用不可。2026年6月時点でも未復活との報告あり

■ カテゴリ3: 2026年に入って追加された機能
□ 日本語UI
→ 現状: 2026年5月7日から対応(英語含む8言語)

□ ループ処理(Repeat for each)
→ 現状: 2026年6月2日から対応。リスト・スプレッドシート最大100行を自動処理

□ Ask a Gem / Ask NotebookLM
→ 現状: 2026年4月・5月に順次追加。プライベートGem・NotebookLMのノートを呼び出せる

■ カテゴリ4: これから変わること(要ウォッチ)
□ 月間の実行回数上限
→ 現状: 2026年9月1日から適用開始予定。詳細な数字は近日公開とされている

□ 外部システム(Salesforce等)との連携
→ 現状: 公式サイトの製品ページでは謳われているが、実際に使えるかは自社環境で要確認
```

**ポイント**: 「公式サイトの説明」欄だけを見て導入判断をせず、必ずカテゴリ2・カテゴリ4を自社環境で実機確認してから本格運用に入ってください。
